# Project 1, Plan D: The `dndm` CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `dndm validate`, `dndm play`, `dndm run` and `dndm sim`, usable by a person or an agent (stepped time, `--json` everywhere, replayable scripts). Add golden replays, a determinism check, and CI.

**Architecture:** `apps/cli` is a thin layer over the engine. A `Driver` holds a game, a clock and the script of everything done, and executes *script lines* (`{ wait }`, `{ next }`, `{ as, command }`). `play` turns typed text into script lines (`parse.ts`). `run` reads script lines from a JSONL file. `sim` drives bot players through `engine.view()` and `engine.apply()`. Output goes through one formatter with a text mode and a JSON-lines mode.

**Tech Stack:** As before. `node:util` `parseArgs`, `node:readline`. Run with `pnpm dndm <command>` (tsx).

**Spec:** `docs/superpowers/specs/2026-10-11-engine-and-packs-design.md` (rev 6), §13 (CLI), §1.2 criteria 1 and 4, §14 (golden replays, determinism, CI).

**Prerequisite:** Plans A, B and C complete.

## Global Constraints

- Time is stepped: it only moves on `wait <duration>` or `next` (spec §13).
- Every command accepts `--json`: one JSON object per line, nothing else on stdout.
- Script lines are exactly `{ "wait": "3s" }`, `{ "next": true }`, or `{ "as": "streamer" | "<character>", "command": { … } }` (spec §13). For viewer commands the CLI fills `command.character` from `as`.
- `--packs` takes folders. A folder outside this repository's `packs/` loads as non-official (data only). Without `--packs`, every folder in `packs/` loads. Without `--channel`, `channels/default.yaml` is used.
- The CLI never refers to a pack ID in code. Defaults come from `listPackDirs()` and `channels/default.yaml`.
- Sim bots read only `engine.describe()`, `engine.view()` and the game state (spec §13).

## Review Focus

1. **A typo in `play`** (`use al atack`, `spwan slime`): a person expects a one-line message and the prompt back, never a crash that ends the session. Test in Task 2.
2. **A short ID that two packs share** (`attack` existing in two enabled packs): a person expects "could be starter:attack or other:attack; write the full ID", not a silent pick. Test in Task 2.
3. **A malformed line in a `run` script**: a person expects the line number and what's wrong, then the run stops with a non-zero exit. Test in Task 3.
4. **`next` when nothing is scheduled**: a person expects "Nothing is scheduled", with time not moving. Test in Task 3.
5. **`sim` against a monster the party can never beat** (a 10,000 HP monster): a person expects the run to stop at `--max-time` and report a timeout, not to loop forever. Test in Task 5.

```ts
import { join, resolve } from 'node:path';
import { createEngine, type Engine } from '@dndm/engine';
import { listPackDirs, loadChannel, loadPacks, repoRoot } from '@dndm/pack-loader';

export interface SetupOpts { packs?: string[]; channel?: string }

export function packDirs(opts: SetupOpts): string[] {
  const given = (opts.packs ?? []).flatMap((p) => p.split(',')).filter(Boolean);
  return given.length ? given.map((p) => resolve(p)) : listPackDirs();
}

export function channelFile(opts: SetupOpts): string {
  return opts.channel ? resolve(opts.channel) : join(repoRoot(), 'channels', 'default.yaml');
}

export async function setup(opts: SetupOpts): Promise<Engine> {
  const bundles = await loadPacks(packDirs(opts));
  return createEngine({ packs: bundles, channel: loadChannel(channelFile(opts)) });
}
```

`apps/cli/src/ids.ts`:
```ts
import type { Description } from '@dndm/engine';

export class CliError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'CliError';
  }
}

export type IdKind = 'ability' | 'item' | 'monster' | 'status' | 'encounter' | 'adventure' | 'class' | 'slot';

function listFor(d: Description, kind: IdKind): { id: string }[] {
  switch (kind) {
    case 'ability': return d.abilities;
    case 'item': return d.items;
    case 'monster': return d.monsters;
    case 'status': return d.statuses;
    case 'encounter': return d.encounters;
    case 'adventure': return d.adventures;
    case 'class': return d.classes;
    case 'slot': return d.slots;
  }
}

/** "slime" -> "starter:slime" when exactly one enabled pack has it. Full IDs pass through. */
export function resolveId(d: Description, kind: IdKind, text: string): string {
  if (text.includes(':')) return text;
  const matches = listFor(d, kind).map((x) => x.id).filter((id) => id.slice(id.indexOf(':') + 1) === text);
  if (matches.length === 1) return matches[0]!;
  if (matches.length === 0) throw new CliError(`Unknown ${kind} '${text}'`);
  throw new CliError(`'${text}' could be ${matches.join(' or ')}; write the full ID`);
}
```

`apps/cli/src/validate.ts`:
```ts
import { formatIssue, ValidationError } from '@dndm/engine';
import { LoadError } from '@dndm/pack-loader';
import { setup, type SetupOpts } from './setup';

const PLURALS: Record<string, string> = { pack: 'packs', class: 'classes', ability: 'abilities', item: 'items', monster: 'monsters', adventure: 'adventures' };
const plural = (n: number, word: string) => `${n} ${n === 1 ? word : PLURALS[word]}`;

export async function validate(opts: SetupOpts & { json?: boolean }): Promise<{ ok: boolean; lines: string[] }> {
  const lines: string[] = [];
  try {
    const engine = await setup(opts);
    const d = engine.describe();
    for (const w of d.warnings) lines.push(opts.json ? JSON.stringify({ kind: 'issue', ...w }) : formatIssue(w));
    const counts = { packs: d.packs.length, classes: d.classes.length, abilities: d.abilities.length, items: d.items.length, monsters: d.monsters.length, adventures: d.adventures.length };
    lines.push(opts.json
      ? JSON.stringify({ kind: 'valid', ...counts })
      : `Valid: ${plural(counts.packs, 'pack')}, ${plural(counts.classes, 'class')}, ${plural(counts.abilities, 'ability')}, ${plural(counts.items, 'item')}, ${plural(counts.monsters, 'monster')}, ${plural(counts.adventures, 'adventure')}`);
    return { ok: true, lines };
  } catch (e) {
    if (e instanceof ValidationError) {
      for (const i of e.issues) lines.push(opts.json ? JSON.stringify({ kind: 'issue', ...i }) : formatIssue(i));
      return { ok: false, lines };
    }
    if (e instanceof LoadError) {
      lines.push(opts.json ? JSON.stringify({ kind: 'issue', level: 'error', message: e.message }) : `error: ${e.message}`);
      return { ok: false, lines };
    }
    throw e;
  }
}
```

`apps/cli/src/main.ts`:
```ts
import type { Readable, Writable } from 'node:stream';
import { parseArgs } from 'node:util';
import { ValidationError, formatIssue } from '@dndm/engine';
import { LoadError } from '@dndm/pack-loader';
import { validate } from './validate';

const USAGE = `Usage: dndm <command> [options]

Commands:
  validate [--packs dirs] [--channel file]                         check packs and a channel config
  play [--packs dirs] [--channel file] [--seed n] [--save file]    play in the terminal (stepped time)
  run <script.jsonl> [--packs dirs] [--channel file] [--seed n]    run a script and print every event
  sim --party <classes> --vs <monster> [--runs n] [--seed n] [--reaction 1s-3s] [--max-time 30m]

Every command takes --json (one JSON object per line).`;

export async function main(argv: string[], io: { stdout: Writable; stdin: Readable } = { stdout: process.stdout, stdin: process.stdin }): Promise<number> {
  const out = (line: string) => io.stdout.write(`${line}\n`);
  let parsed;
  try {
    parsed = parseArgs({
      args: argv, allowPositionals: true,
      options: {
        packs: { type: 'string', multiple: true }, channel: { type: 'string' }, seed: { type: 'string' },
        json: { type: 'boolean' }, save: { type: 'string' }, party: { type: 'string' }, vs: { type: 'string' },
        runs: { type: 'string' }, reaction: { type: 'string' }, 'max-time': { type: 'string' }, help: { type: 'boolean', short: 'h' },
      },
    });
  } catch (e) {
    out((e as Error).message);
    out(USAGE);
    return 2;
  }
  const { values, positionals } = parsed;
  const [cmd, ...rest] = positionals;
  const common = { packs: values.packs, channel: values.channel, json: values.json };
  const seed = values.seed !== undefined ? Number(values.seed) : 1;
  try {
    switch (cmd) {
      case 'validate': {
        const r = await validate(common);
        r.lines.forEach(out);
        return r.ok ? 0 : 1;
      }
      case 'play': {
        const { play } = await import('./play');
        await play({ ...common, seed, save: values.save, input: io.stdin, output: io.stdout });
        return 0;
      }
      case 'run': {
        if (!rest[0]) { out('Usage: dndm run <script.jsonl>'); return 2; }
        const { runFile } = await import('./run');
        return await runFile(rest[0], { ...common, seed, write: out });
      }
      case 'sim': {
        const { simCommand } = await import('./sim');
        return await simCommand({ ...common, seed, party: values.party, vs: values.vs, runs: values.runs, reaction: values.reaction, maxTime: values['max-time'], write: out });
      }
      default:
        out(USAGE);
        return cmd === undefined || values.help ? 0 : 2;
    }
  } catch (e) {
    if (e instanceof ValidationError) { e.issues.forEach((i) => out(formatIssue(i))); return 1; }
    if (e instanceof LoadError) { out(`error: ${e.message}`); return 1; }
    throw e;
  }
}

if (import.meta.url === `file://${process.argv[1]}`) {
  main(process.argv.slice(2)).then((code) => process.exit(code));
}
```

`apps/cli/src/parse.ts`:
```ts
import { type Command, type Description, parseDuration } from '@dndm/engine';
import { CliError, type IdKind, resolveId } from './ids';

export type ScriptLine = { wait: string | number } | { next: true } | { as: string; command: Record<string, unknown> };
export type Action =
  | { kind: 'script'; line: ScriptLine }
  | { kind: 'state' } | { kind: 'view'; id: string } | { kind: 'describe' } | { kind: 'help' } | { kind: 'quit' };

export const HELP = `Viewer commands (first word after the command is the character):
  join <char> [class-item]   leave <char>       use <char> <ability> [target|monster]
  equip <char> <item>        unequip <char> <slot>
  vote <char> <choice>       tap <char>         buy <char> <item>     respond <char> [json]
Streamer commands:
  open | close               spawn <monster>    start <encounter>     end [outcome]
  adventure <id> | go | skip <node> | stop
  heal <char|party> [amount|full]    revive <char|all>    ko <char>
  status <char|monster> <status> [duration] [json params]    unstatus <char|monster> <status>
  act | hold | release | monster-hp <n>
  give-xp <char|party> <n>   give-gold <char|party> <n>   give-item <char|party> <item>
  remove <char> | ban <char> | unban <char> | say <text>
Time and info:
  wait <duration> | next | state | view <char> | describe | help | quit
Short IDs work when only one pack has them (spawn slime); otherwise write pack:id.`;

const entity = (t: string) => (t === 'monster' || t === 'm1' ? { kind: 'monster', id: 'm1' } : { kind: 'character', id: t });

export function parseLine(input: string, d: Description): Action | null {
  const text = input.trim();
  if (!text || text.startsWith('#')) return null;
  const [cmd, ...args] = text.split(/\s+/) as [string, ...string[]];
  const need = (n: number, usage: string) => { if (args.length < n) throw new CliError(`Usage: ${usage}`); };
  const id = (kind: IdKind, t: string) => resolveId(d, kind, t);
  const rest = (from: number) => args.slice(from).join(' ');
  const json = (raw: string, usage: string): unknown => {
    if (!raw) return {};
    try { return JSON.parse(raw); } catch { throw new CliError(`Usage: ${usage} (write params as JSON)`); }
  };
  const S = (command: Command): Action => ({ kind: 'script', line: { as: 'streamer', command: command as unknown as Record<string, unknown> } });
  const V = (who: string, command: Record<string, unknown>): Action => ({ kind: 'script', line: { as: who, command } });
  const a0 = args[0]!;
  const a1 = args[1]!;

  switch (cmd) {
```

```ts
import { type Command, type Engine, type GameEvent, type GameState, parseDuration } from '@dndm/engine';
import { CliError } from './ids';
import type { ScriptLine } from './parse';

export type { ScriptLine } from './parse';

const VIEWER = new Set(['join', 'leave', 'use', 'equip', 'unequip', 'respond']);

export interface Output {
  kind: 'event' | 'rejected' | 'note';
  at: number;
  text: string;
  event?: GameEvent;
  as?: string;
  code?: string;
}

const fromEvent = (e: GameEvent): Output => ({ kind: 'event', at: e.at, text: e.text, event: e });

export class Driver {
  game: GameState;
  now = 0;
  readonly script: ScriptLine[] = [];

  constructor(readonly engine: Engine, seed: number) {
    this.game = engine.newGame({ seed });
  }

  exec(line: ScriptLine): Output[] {
    this.script.push(line);
    if ('wait' in line) {
      this.now += parseDuration(line.wait);
      return this.advance();
    }
    if ('next' in line) {
      const t = this.engine.nextWakeTime(this.game);
      if (t === null) return [{ kind: 'note', at: this.now, text: 'Nothing is scheduled' }];
      this.now = Math.max(this.now, t);
      return this.advance();
    }
    const command = (line.as !== 'streamer' && VIEWER.has(String(line.command.type))
      ? { ...line.command, character: line.as }
      : line.command) as unknown as Command;
    const r = this.engine.apply(this.game, command, this.now);
    if (!r.ok) return [{ kind: 'rejected', at: this.now, as: line.as, code: r.error.code, text: r.error.message }];
    this.game = r.game;
    return r.events.map(fromEvent);
  }

  private advance(): Output[] {
    const r = this.engine.advance(this.game, this.now);
    this.game = r.game;
    return r.events.map(fromEvent);
  }
}

export function formatOutput(o: Output, json: boolean): string {
  if (json) {
    if (o.kind === 'event') return JSON.stringify({ kind: 'event', ...o.event });
    return JSON.stringify({ kind: o.kind, at: o.at, ...(o.as ? { as: o.as } : {}), ...(o.code ? { code: o.code } : {}), text: o.text });
  }
  const t = `[${(o.at / 1000).toFixed(1).padStart(7)}s]`;
  if (o.kind === 'rejected') return `${t} ✗ ${o.as}: ${o.text} (${o.code})`;
  if (o.kind === 'note') return `${t} · ${o.text}`;
  return `${t} ${o.text}`;
}

const isObj = (v: unknown): v is Record<string, unknown> => typeof v === 'object' && v !== null && !Array.isArray(v);

export function parseScriptLine(text: string, lineNo: number): ScriptLine {
  let v: unknown;
  try { v = JSON.parse(text); } catch (e) { throw new CliError(`line ${lineNo}: not JSON (${(e as Error).message})`); }
  if (isObj(v) && 'wait' in v && (typeof v.wait === 'string' || typeof v.wait === 'number')) {
    try { parseDuration(v.wait); } catch (e) { throw new CliError(`line ${lineNo}: ${(e as Error).message}`); }
    return { wait: v.wait };
  }
  if (isObj(v) && v.next === true) return { next: true };
  if (isObj(v) && typeof v.as === 'string' && isObj(v.command) && typeof v.command.type === 'string') return { as: v.as, command: v.command };
  throw new CliError(`line ${lineNo}: expected {"wait"}, {"next"} or {"as", "command"}`);
}
```

```ts
import { readFileSync } from 'node:fs';
import type { Engine } from '@dndm/engine';
import { Driver, formatOutput, parseScriptLine } from './driver';
import { CliError } from './ids';
import { setup, type SetupOpts } from './setup';

export function runLines(lines: string[], opts: { engine: Engine; seed: number; json?: boolean }): string[] {
  const driver = new Driver(opts.engine, opts.seed);
  const out: string[] = [];
  lines.forEach((text, i) => {
    if (!text.trim()) return;
    const line = parseScriptLine(text, i + 1);
    for (const o of driver.exec(line)) out.push(formatOutput(o, !!opts.json));
  });
  return out;
}

export async function runFile(file: string, opts: SetupOpts & { seed: number; json?: boolean; write: (line: string) => void }): Promise<number> {
  const engine = await setup(opts);
  const lines = readFileSync(file, 'utf8').split('\n');
  try {
    for (const l of runLines(lines, { engine, seed: opts.seed, json: opts.json })) opts.write(l);
    return 0;
  } catch (e) {
    if (e instanceof CliError) {
      opts.write(opts.json ? JSON.stringify({ kind: 'error', text: e.message }) : `error: ${e.message}`);
      return 1;
    }
    throw e;
  }
}
```

`runLines` throws on the first malformed line before printing anything from later lines. `runFile` therefore prints nothing but the error for a bad script. That matches the test (`lines.at(-1)` is the error). If you'd rather stream earlier output, buffer per line instead; keep the error last.

```ts
import { writeFileSync } from 'node:fs';
import { createInterface } from 'node:readline';
import type { Readable, Writable } from 'node:stream';
import { Driver, formatOutput } from './driver';
import { CliError } from './ids';
import { HELP, parseLine } from './parse';
import { renderScene, renderState, renderView } from './render';
import { setup, type SetupOpts } from './setup';

function save(file: string, driver: Driver): void {
  writeFileSync(file, `${JSON.stringify(driver.game, null, 2)}\n`);
  writeFileSync(`${file}.script.jsonl`, driver.script.map((l) => JSON.stringify(l)).join('\n') + (driver.script.length ? '\n' : ''));
}

export async function play(opts: SetupOpts & { seed: number; json?: boolean; save?: string; input: Readable; output: Writable }): Promise<void> {
  const engine = await setup(opts);
  const desc = engine.describe();
  const driver = new Driver(engine, opts.seed);
  const json = !!opts.json;
  const interactive = !json && 'isTTY' in opts.input && !!(opts.input as { isTTY?: boolean }).isTTY;
  const write = (line: string) => opts.output.write(`${line}\n`);
  const note = (text: string) => write(json ? JSON.stringify({ kind: 'error', text }) : `! ${text}`);

  if (!json) write(`dndm play: ${desc.packs.map((p) => p.name).join(', ')}. Type help for commands. Time only moves with wait or next.`);
  const rl = createInterface({ input: opts.input, ...(interactive ? { output: opts.output, terminal: true } : {}) });
  let lastScene = '';
  if (interactive) { rl.setPrompt('> '); rl.prompt(); }

  for await (const text of rl) {
    let quit = false;
    try {
      const action = parseLine(text, desc);
      if (action) {
        switch (action.kind) {
          case 'quit': quit = true; break;
          case 'help': if (!json) write(HELP); break;
          case 'describe': write(JSON.stringify(desc, json ? undefined : null, json ? undefined : 2)); break;
          case 'state': {
            const v = engine.view(driver.game, null, driver.now);
            if (json) write(JSON.stringify({ kind: 'state', ...v }));
            else renderState(v).forEach(write);
            break;
          }
          case 'view': {
            const v = engine.view(driver.game, action.id, driver.now);
            if (json) write(JSON.stringify({ kind: 'view', ...v }));
            else renderView(v).forEach(write);
            break;
          }
          case 'script': {
            for (const o of driver.exec(action.line)) write(formatOutput(o, json));
            if (!json) {
              const scene = engine.view(driver.game, null, driver.now).overlay;
              const key = JSON.stringify(scene);
              if (scene && key !== lastScene) renderScene(scene).forEach(write);
              lastScene = key;
            }
            break;
          }
        }
      }
    } catch (e) {
      if (e instanceof CliError) note(e.message);
      else throw e;
    }
    if (opts.save) save(opts.save, driver);
    if (quit) break;
    if (interactive) rl.prompt();
  }
  rl.close();
}
```

```ts
/** Small seeded RNG (mulberry32) for bot decisions, so sim runs are repeatable. */
export function makeRng(seed: number): () => number {
  let s = (Math.floor(seed) >>> 0) || 0x9e3779b9;
  return () => {
    s = (s + 0x6d2b79f5) >>> 0;
    let r = Math.imul(s ^ (s >>> 15), s | 1);
    r ^= r + Math.imul(r ^ (r >>> 7), r | 61);
    return ((r ^ (r >>> 14)) >>> 0) / 4294967296;
  };
}
```

`apps/cli/src/sim.ts`:
```ts
import { type Command, type Engine, type EntityRef, type GameEvent, type GameState, parseDuration } from '@dndm/engine';
import { CliError, resolveId } from './ids';
import { makeRng } from './rng';
import { setup, type SetupOpts } from './setup';

export interface SimOptions {
  engine: Engine;
  party: string[];
  vs: string;
  runs: number;
  seed: number;
  reaction: [number, number];
  maxTime: number;
}

export interface SimReport {
  runs: number;
  wins: number;
  winRate: number;
  timeouts: number;
  avgDuration: number;
  avgKnockouts: number;
  byAbility: { ability: string; uses: number; damage: number; healing: number }[];
}

interface Tally { uses: number; damage: number; healing: number }

function tallyEvents(events: GameEvent[], byAbility: Map<string, Tally>): number {
  let current: { user: EntityRef; ability: string } | null = null;
  let knockouts = 0;
  const get = (a: string) => byAbility.get(a) ?? (byAbility.set(a, { uses: 0, damage: 0, healing: 0 }), byAbility.get(a)!);
  for (const e of events) {
    if (e.type === 'core:ability-used') {
      current = { user: e.data.user as EntityRef, ability: e.data.ability as string };
      get(current.ability).uses++;
    } else if ((e.type === 'core:damaged' || e.type === 'core:healed') && current) {
      const src = e.data.source as EntityRef | null;
      if (src && src.kind === current.user.kind && src.id === current.user.id && typeof e.data.amount === 'number') {
        if (e.type === 'core:damaged') get(current.ability).damage += e.data.amount;
        else get(current.ability).healing += e.data.amount;
      }
    } else if (e.type === 'core:knocked-out' && (e.data.entity as EntityRef).kind === 'character') {
      knockouts++;
    }
  }
  return knockouts;
}

export function simulate(o: SimOptions): SimReport {
  const d = o.engine.describe();
  const classSlot = d.settings.classSlot;
  const classes = o.party.map((c) => resolveId(d, 'class', c));
  const monster = resolveId(d, 'monster', o.vs);
  const itemFor = (cls: string) => {
    const item = d.items.find((i) => i.grantsClass === cls && i.slot === classSlot);
    if (!item) throw new CliError(`No item grants ${cls} in the class slot`);
    return item;
  };
  const byAbility = new Map<string, Tally>();
  let wins = 0, timeouts = 0, totalDuration = 0, totalKnockouts = 0;

  for (let run = 0; run < o.runs; run++) {
    const rand = makeRng(o.seed * 7919 + run);
    let game: GameState = o.engine.newGame({ seed: o.seed + run });
    let now = 0;
    const events: GameEvent[] = [];
    const apply = (cmd: Command): boolean => {
      const r = o.engine.apply(game, cmd, now);
      if (!r.ok) return false;
      game = r.game;
      events.push(...r.events);
      return true;
    };
    const reaction = () => o.reaction[0] + Math.floor(rand() * (o.reaction[1] - o.reaction[0] + 1));

    apply({ type: 'openSession' });
    const bots = classes.map((cls, i) => {
      const id = `bot${i + 1}`;
      const item = itemFor(cls);
      if (!item.starting) apply({ type: 'giveItem', target: id, item: item.id });
      apply({ type: 'join', character: id, name: `${d.classes.find((c) => c.id === cls)!.name} ${i + 1}`, pick: item.id });
      return id;
    });
    if (!apply({ type: 'spawnMonster', monster })) throw new CliError(`Can't spawn ${monster}`);
    const start = now;
    const nextAct = new Map(bots.map((b) => [b, now + reaction()]));
    let outcome: string | null = null;

    while (outcome === null) {
      const wake = o.engine.nextWakeTime(game) ?? Infinity;
      const t = Math.min(wake, ...nextAct.values());
      if (t === Infinity) break;
      if (t - start > o.maxTime) {
        now = start + o.maxTime;
        apply({ type: 'endEncounter', outcome: 'ended' });
        outcome = 'timeout';
        break;
      }
      now = Math.max(now, t);
      const adv = o.engine.advance(game, now);
      game = adv.game;
      events.push(...adv.events);
      for (const bot of bots) {
        if (!game.session?.encounter) break;
        if ((nextAct.get(bot) ?? Infinity) > now) continue;
        const v = o.engine.view(game, bot, now);
        const ready = v.abilities.filter((a) => a.ready && a.targets.length > 0);
        if (ready.length) {
          const pick = ready[Math.floor(rand() * ready.length)]!;
          let chosen: EntityRef | null = null;
          if (pick.needsChoice) {
            const party = new Map(v.party.map((m) => [m.id, m]));
            chosen = [...pick.targets].sort((a, b) => {
              const ma = party.get(a.id), mb = party.get(b.id);
              const ka = ma?.knockedOut ? -1 : (ma ? ma.hp / ma.maxHp : 1);
              const kb = mb?.knockedOut ? -1 : (mb ? mb.hp / mb.maxHp : 1);
              return ka - kb;
            })[0]!;
          }
          apply({ type: 'use', character: bot, ability: pick.ability, ...(chosen ? { chosen } : {}) });
        }
        const after = o.engine.view(game, bot, now);
        const soonest = Math.min(...after.abilities.map((a) => a.readyAt ?? Infinity), now + 1000);
        nextAct.set(bot, Math.max(now + 1, soonest) + reaction());
      }
      const ended = [...events].reverse().find((e) => e.type === 'core:encounter-ended');
      if (!game.session?.encounter && ended) outcome = ended.data.outcome as string;
    }

    if (outcome === 'won') wins++;
    if (outcome === 'timeout') timeouts++;
    totalDuration += now - start;
    totalKnockouts += tallyEvents(events, byAbility);
  }

  return {
    runs: o.runs, wins, winRate: o.runs ? wins / o.runs : 0, timeouts,
    avgDuration: o.runs ? Math.round(totalDuration / o.runs) : 0,
    avgKnockouts: o.runs ? totalKnockouts / o.runs : 0,
    byAbility: [...byAbility.entries()].map(([ability, t]) => ({ ability, ...t })).sort((a, b) => a.ability.localeCompare(b.ability)),
  };
}

function parseReaction(text: string | undefined): [number, number] {
  if (!text) return [0, 0];
  const [lo, hi] = text.split('-');
  return [parseDuration(lo!), parseDuration(hi ?? lo!)];
}

export async function simCommand(opts: SetupOpts & {
  seed: number; party?: string; vs?: string; runs?: string; reaction?: string; maxTime?: string; json?: boolean; write: (line: string) => void;
}): Promise<number> {
  try {
    if (!opts.party || !opts.vs) throw new CliError('Usage: dndm sim --party <classes> --vs <monster>');
    const engine = await setup(opts);
    const report = simulate({
      engine, party: opts.party.split(','), vs: opts.vs, runs: opts.runs ? Number(opts.runs) : 100, seed: opts.seed,
      reaction: parseReaction(opts.reaction), maxTime: parseDuration(opts.maxTime ?? '30m'),
    });
    if (opts.json) {
      opts.write(JSON.stringify({ kind: 'sim', ...report }));
      return 0;
    }
    opts.write(`Runs: ${report.runs}   Win rate: ${Math.round(report.winRate * 100)}%   Timeouts: ${report.timeouts}`);
    opts.write(`Average fight: ${(report.avgDuration / 1000).toFixed(1)}s   Average knockouts: ${report.avgKnockouts.toFixed(2)}`);
    opts.write('Ability                        uses     damage    healing');
    for (const a of report.byAbility) {
      opts.write(`${a.ability.padEnd(28)} ${String(a.uses).padStart(6)} ${String(a.damage).padStart(10)} ${String(a.healing).padStart(10)}`);
    }
    return 0;
  } catch (e) {
    if (e instanceof CliError) { opts.write(opts.json ? JSON.stringify({ kind: 'error', text: e.message }) : `error: ${e.message}`); return 2; }
    throw e;
  }
}
```
